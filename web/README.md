# echostream web demo · 回响流转

A small Vite + React 18 + TypeScript front end for the echostream cluster. No UI or chart
library: plain CSS and inline SVG.

## Run

```bash
# 1. backend cluster, from the repo root (demo mode turns on the chaos buttons)
make demo            # also regenerates web/public/data and starts this UI on :5173

# or, if the cluster is already running:
cd web
npm install && npm run dev      # http://127.0.0.1:5173
```

The API base URL defaults to `http://127.0.0.1:17000` (the nginx load balancer in front of
the API replicas). Override it with `VITE_API=http://host:port npm run dev`.

## Pages

| tab | reads | shows |
| --- | --- | --- |
| Feed | `GET /recommend`, `POST /events` | cards with recall-source badges, Watched / Skip buttons that post an event and refresh ~400 ms later, new items highlighted, dropped items listed, degraded labels, and the latency waterfall (stages + per-shard calls with failed attempts in red) |
| Cluster | `GET /cluster`, `GET /supervisor/status` every 2 s, `POST /chaos/{action}` | shards × replicas, feature nodes, workers, partition lag, DLQ, API replicas, every process with kill / stop / start (+ freeze/thaw for `redis-feat*`, slow 500ms / unslow for shards) |
| A/B | `/data/ab.json` | arms as a CI dot plot, Holm-corrected comparisons, within-subjects results, offline-vs-online ranks with the disagreeing pairs |
| Quality | `/data/quality.json`, `/data/systems.json`, `/data/journey.json` | NDCG@10 CI bars per model, MMR trade-off, eval history, systems summaries, project timeline |

The files in `public/data/` are generated by `scripts/build_web_data.py` from `results/`
(`make web-data`). No number is typed into the UI; a missing file or field shows
"not measured yet".

## Test and build

```bash
npm test         # vitest + Testing Library + jsdom, fetch is mocked
npm run build    # type-check + production build into dist/
```

## Layout

```
src/
  api.ts                 fetch helpers, API base URL, /data loader
  format.ts              number / CI formatting
  types.ts               response shapes
  App.tsx                header, tab bar, footer
  pages/                 Feed, Cluster, AB, Quality
  components/            Waterfall, Journey (timeline), charts (CI plot, x-y chart, table)
  test/                  one test file per feature
```
